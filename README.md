# Aquino_2026_Front_Ethol
Data and analysis code associated with the Aquino et al 2026 publication in Frontiers in Ethology titled "Behavior in asymmetric dominance pairings predicts physiology, neural response, and neurogenesis in a social cichlid fish"

Note that all analyses except the principal component analysis were conducted in Python (see .md file) and used three excel files. The principal component analyses was conducted in R (see .rmd file) and used one csv file.
